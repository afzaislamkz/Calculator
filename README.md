# Calculator
A simple and interactive **Calculator** built using **HTML, CSS, and JavaScript**.
This project performs basic arithmetic operations with a clean dark UI and orange operator buttons.

---

## 🌙 UI Theme
This project features a **Dark Mode UI with an Orange Operator Theme**, giving it a modern and functional look.

---

## 🚀 Features
* ➕ Addition, Subtraction, Multiplication, Division
* ⌫ Backspace button to delete last digit
* 🔄 Clear (C) button to reset display
* 🔢 Decimal point support
* 🎨 Clean dark UI with orange operator buttons
* 📐 CSS Grid button layout
* 🚫 Division by zero protection

```
git clone https://github.com/afzaislamkz/Calculator.git
```
2. Open the project folder
3. Run `index.html` in your browser

---

## 🎯 How It Works
* Click any **number button** to enter digits
* Click an **operator button** ( ÷ × − + ) to choose operation
* Click **=** to see the result
* Click **⌫** to delete last digit
* Click **C** to clear everything
